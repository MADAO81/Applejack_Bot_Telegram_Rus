## 📖 О проекте

Эпплджек — это интерактивный бот, который:

- 🍎 **Даёт честные и практичные советы** — никакой лжи, только правда.
- 🥧 **Делится деревенскими рецептами** — от яблочного пирога до самогона и настоек.
- 🌾 **Помогает по хозяйству** — советы по огороду, ферме, быту.
- 💪 **Мотивирует** — подбадривает, когда трудно.
- 👨‍👩‍👧‍👦 **Рассказывает о семье и традициях** — история фермы «Сладкое Яблоко».
- 🗣️ **Говорит с южным колоритом** — «Ёкарный бабай!», «Дюже», «Тю!».
- 💬 **Общается с характером Эпплджек** — честная, трудолюбивая, надёжная.

## 🥧 Рецепты

Эпплджек знает множество деревенских рецептов:

- **Выпечка:** яблочный пирог, шарлотка, яблочные кексы.
- **Напитки:** яблочный сидр, компот.
- **Самогон и настойки:** самогон на яблоках, настойка на хрене, яблочная наливка.
- **Закрутки:** яблочное варенье, повидло.
- **Деревенская кухня:** окрошка, печёная картошка, домашний хлеб.

Поиск работает по названию, категории и даже по корню слова:
- `/recipe яблочный пирог` — найдёт классический рецепт.
- `/recipe настойка` — покажет рецепт настойки.
- `/recipe яблоко` — найдёт все рецепты с яблоками.

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone https://github.com
cd Applejack_Bot_Telegram_Rus
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv
source venv/bin/activate  # Для Linux/Mac
# или
venv\Scripts\activate     # Для Windows
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения

Скопируйте файл `.env.example` в `.env` и заполните его:

```env
# Telegram
TELEGRAM_TOKEN=ваш_токен_бота

# DeepSeek
DEEPSEEK_API_KEY=ваш_ключ
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_MAX_TOKENS=2000
DEEPSEEK_TEMPERATURE=0.7

# Координаты Ворсино
DEFAULT_LAT=55.0965
DEFAULT_LON=36.6355

# Настройки
WORK_START_HOUR=9
WORK_END_HOUR=22
CONTEXT_EXPIRE_DAYS=30

# Администратор
ADMIN_ID=ваш_telegram_id

# Режим отладки
DEBUG_MODE=false
```

### 5. Создайте базу рецептов

```bash
python3 bot/scripts/create_recipes_db.py
python3 bot/scripts/fill_recipes_db.py
```

### 6. Запустите бота

```bash
python run.py
```

## 📝 Особенности поведения

### 🎯 Реакция на сообщения в группах

| Ситуация | Поведение |
|:---|:---|
| Упоминание бота (`@username`) | ✅ Всегда отвечает |
| Ответ на сообщение бота | ✅ Всегда отвечает |
| Обычное сообщение (без упоминания) | ❌ Не отвечает |
| Личное сообщение | ✅ Всегда отвечает |

### ⏰ Рабочее время

**Понедельник — Воскресенье: с 09:00 до 22:00**

* **Внутри рабочего окна:** бот функционирует в стандартном режиме.
* **Вне рабочего окна:** полностью игнорирует сообщения в группах. При попытке написать в личные сообщения отвечает: *«Я отдыхаю, приходите завтра!»*.
